# Contributing to Practice Service Matrix

Use Issues for a reproducible bug and Discussions for questions or improvements. Include a minimal synthetic example, expected output, actual output and runtime/browser version. Keep client records, personal data and credentials private.

Run `npm test` and `npm run build` on Node.js 22 or later. Add a meaningful fixture for a changed decision. Keep the resource small, framework-independent and usable without a paid account. Do not add tracking, mandatory attribution links or data uploads. All contributions must be compatible with the MIT licence.
